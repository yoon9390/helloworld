# 📊 마크다운 보드/그래프 비교 실험실

> 마크다운 더미를 "한눈에 보는" 세 가지 방법을 나란히 깔아놨어요.
> 직접 깔아보고, 눈에 제일 잘 들어오는 걸 고르면 됩니다.
> **여긴 `board-experiment` 라는 평행세계(브랜치)예요. 맘에 안 들면 통째로 버려도 본체(main)는 멀쩡합니다.**

---

## 🧭 시작하기 전에 — 딱 한 번만 클릭

1. VS Code에서 **이 폴더(helloworld)를 통째로** 엽니다.
2. 오른쪽 아래에 *"이 작업영역에 추천 확장이 있어요. 설치할까요?"* 라는 쪽지가 뜹니다.
   → **Install All(모두 설치)** 클릭. (안 떠도 괜찮아요. 아래 방법으로 직접 깔면 됩니다.)
3. 끝. 이제 아래 세 개를 하나씩 열어보세요.

> 💡 확장 설치하는 법(쪽지가 안 떴을 때): 왼쪽 세로 막대에서 **블록 4개 모양 아이콘**(확장) 클릭 → 검색창에 이름 입력 → **Install**.

## 1️⃣ Foam — "생각의 별자리"

- **무엇**: 노트끼리 `[[이중대괄호]]`로 연결해두면, 점과 선으로 된 **별자리 지도**를 그려줍니다.
- **언제 좋나**: "이 아이디어가 저 아이디어랑 어떻게 이어지지?"를 보고 싶을 때. (지하철 노선도 느낌)
- **깔 것**: 확장 `Foam`  (검색: `foam`)
- **보는 법**:
  1. [foam-데모/홈.md](foam-데모/홈.md) 파일을 엽니다.
  2. `Cmd+Shift+P` (명령 팔레트 = VS Code 검색창) → `Foam: Show Graph` 입력 → 엔터.
  3. 점을 클릭하면 연결된 노트로 점프! 마우스로 끌어서 돌려볼 수도 있어요.
- **체험 포인트**: `[[기획-요약]]` 같은 글자에 마우스를 올리면 미리보기가 뜨고, `Ctrl/Cmd+클릭`하면 그리로 이동합니다.

## 2️⃣ Markdown Kanban — "디지털 포스트잇 보드"

- **무엇**: 마크다운 파일 하나를 **"할 일 / 작업중 / 완료" 칸이 있는 보드**로 보여줍니다.
- **언제 좋나**: 아이디어를 카드로 만들어 칸 사이로 **끌어다 옮기며** 진행 상황을 관리할 때.
- **깔 것**: 확장 `Unified Kanban` (검색: `unified kanban`). 안 맞으면 `MD Kanban`.
- **보는 법**:
  1. [칸반보드.md](칸반보드.md) 파일을 엽니다.
  2. 파일 오른쪽 위(또는 우클릭 메뉴)의 **"Open as Kanban / 보드로 열기"** 버튼 클릭.
  3. 카드를 마우스로 잡아 다른 칸으로 끌어보세요. → 그러면 **밑의 마크다운 글자도 자동으로 바뀝니다.** (그림과 글이 한 몸!)

## 3️⃣ GitHub Projects — "웹에 사는 공유 보드"

- **무엇**: 깃허브 웹사이트(github.com)에 사는 보드. 설치가 **아예 없습니다.**
- **언제 좋나**: 인터넷만 되면 어디서든(아이패드·폰 포함) 보고, 남과 같이 쓰고 싶을 때.
- **하는 법**: [깃허브-프로젝트-안내.md](깃허브-프로젝트-안내.md) 참고. (클릭 5번이면 끝나요)
