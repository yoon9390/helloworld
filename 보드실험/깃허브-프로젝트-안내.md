# 🌐 GitHub Projects 켜보기 (설치 없음, 웹에서)

GitHub Projects는 깔 게 없어요. 작가님 깃허브 계정에 이미 딸려 있는 기능이라,
**브라우저에서 클릭 몇 번**이면 보드가 생깁니다. 아이패드·폰에서도 보여요.

## 따라하기

1. 브라우저로 깃허브 저장소에 갑니다 →
   https://github.com/yoon9390/helloworld
2. 위쪽 가로 메뉴에서 **Projects** 탭 클릭.
3. **New project**(초록 버튼) 클릭 → 템플릿 고르는 창이 떠요.
4. **Board**(칸반 보드 모양) 선택 → **Create**.
5. 끝! "Todo / In Progress / Done" 칸이 있는 보드가 생깁니다.
   - **+ Add item**으로 카드를 추가하고, 마우스로 칸 사이를 끌어 옮겨보세요.

## 우리 레포랑 연결하는 보너스

- 카드를 그냥 메모로 써도 되고,
- 나중에 "이슈(Issue)"라는 깃허브 할 일 쪽지와 연결하면,
  코드/문서 변경과 보드가 자동으로 연동돼요. (지금은 몰라도 됩니다.)

## 솔직한 장단점

- 👍 인터넷만 되면 어디서든, 남과 같이 보기 최고.
- 👎 이건 **마크다운 파일이 아니라 깃허브 웹의 별도 데이터**라,
  레포 안 `.md` 파일과 자동으로 같아지진 않아요. (Foam·Kanban은 글 자체가 보드예요.)
